# Packets

Work packets, shaped before `/spec-to-ship` runs: `PNN-name.md`, each with a
`Depends on:` header that is authoritative for ordering.

A packet owns **scope and shape** — what is being built, why it is this shape,
and what is explicitly out. The spec (phase 1) owns **behaviour**. Keep the queue
readable here so the next packet can be picked without opening every spec.
